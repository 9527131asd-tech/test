# 功能覆盖与后续增强项

## 当前实现覆盖

赛题的核心流程已覆盖：实验室和设备、分角色预约、冲突校验、签到签退、缺席违约、报修维护、耗材库存与审批、实验报告上传批改、基础统计和操作日志。

## 需要在正式竞赛交付前增强

- 短信或站内通知尚未接入第三方服务；可先增加站内消息表和站内信页面。
- JasperReports PDF/Excel 报表、邮件发送与图表大屏尚未接入；当前提供基础统计 API。
- 维护计划目前由故障处理记录体现，周期性维护排程页面和提醒需要扩展。
- 实验室开放时间目前作为描述字段维护；若要严格校验每日开放时段，应增加按星期拆分的开放时间表及节假日规则。
- 实验报告上传目录是单机本地存储；多实例部署改为对象存储并加权限下载接口。
- 演示账号在首次启动创建，生产使用前要更换密码并补充账号管理、密码重置和登录审计。
- 性能和并发指标须在实际服务器上执行并记录压测报告；本仓库只给出用例与索引设计，没有虚构结果。
